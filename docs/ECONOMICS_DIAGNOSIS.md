# 恢复原机组后的经济量纲核查

小规模unified37_smoke_s42_v2完成26小时MPC前序和6条六小时分支，AC全部通过，但快充服务全部报警。核查原始数据发现：10个FCS合计有明确的充电需求和约10 MW当期车辆功率能力，MPC仍给出全部0功率，故不能将该批排队作为研究发现。

原生10台机组的曲线是500P²+1000P+10（P以MW，原生成本单位），并非原来仅按约30/MWh进口价计算的目标。沿用旧cost_scale=50，使正常发电的归一化代价超过服务缺口惩罚，形成经济量纲错配。

修正方案：以原生机组在独立基准负荷均分时的边际费用定义成本参考，不改变成本曲线。经济目标统一除以该参考；备用、非EV失供、弃发代价也从同一原生费用尺度定义，并在MPC及执行端共用。服务、资源与功率变化仍保留其物理量及独立归一化，动态偏好不是将不同物理单位直接相加。增加“健康网况、已有明确快充需求时，平衡偏好必须安排快充”的回归测试。

原生路网/电网/线路/桩位及所有P/Q能力均不调整。v1为审查中止版本；v2保留为经济量纲诊断，不能进入正式重训和论文风险发现证据。修正后使用新的物理/运营合同版本和新的RunId从头重跑，旧RL和专家仍冻结。

进一步的一小时富余风光检查发现，单独给新能源负边际成本会奖励I²R耗散。固定交付时所有电源有功和等于固定净负荷与AC损耗之和，因此给各电源统一增加正边际项，等价于AC损耗正则加一个常量。当前损耗系数2278.895，大于弃发奖励455.779；原机组二次/一次曲线仍保留，正则作为执行端单独的优化分项，不混入货币费用，也不加到无损耗MPC的可变充电需求中。

回归工况[load16, wind1, solar30]MW在全供电、无备用条件下可获得有效AC、损耗低于1 MWh且弃发超过14 MWh，避免以发热虚增消纳。最终完整小运行使用unified37_smoke_s42_v4，26小时暖启动与36个分支小时全部AC通过，之前v3作为缺少这一损耗约束的诊断保留。
